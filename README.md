# 국가의 시간 · 1936

1936년 프랑스 제3공화국을 운영하는 브라우저 전략 시뮬레이터의 첫 플레이 버전입니다.

## 실행

Node.js 20 이상에서 `npm run dev`를 실행한 뒤 `http://localhost:4173`에 접속하세요. 의존성 설치는 필요하지 않습니다. `npm test`로 경제, 이벤트, 세이브 동작을 검증할 수 있습니다.

## 현재 구현

- 월 단위 시간 진행과 상호 연결된 세금, 예산, 성장, 실업, 물가, 여론, 안정도, 군수 모델
- 라인란트 진주부터 스페인 내전까지 1936년 사건 선택지와 1937년의 조건부 후속 사건
- 산업 투자, 사단 편성, 국가별 외교 행동
- 로컬 세이브 슬롯 세 개, Supabase 이메일 계정과 클라우드 세이브 슬롯 세 개
- 상황실, 경제, 정치, 군사, 외교, 연대기 화면과 모바일 레이아웃

역사적 사건의 배경과 게임의 계산 모델은 구분됩니다. 국가의 **1936년 기본 윤곽**은 ETH Zürich의 [CShapes 2.1](https://icr.ethz.ch/data/cshapes/beta.html) 시기별 경계 자료에서 1936년 1월 1일 유효한 유럽 국가를 추출한 것입니다. 독일 본토와 동프로이센, 폴란드, 자유시 단치히를 당시의 서로 다른 영역으로 표시합니다. 자료 출처: Schvitz, Rüegger, Girardin, Cederman, Weidmann, Gleditsch (2022), *Mapping The International System, 1886–2017: The CShapes 2.0 Dataset*. 이 지도 데이터 및 가공한 `src/historical1936.js`는 **CC BY-NC-SA 4.0** 조건을 따릅니다. 비상업적 사용, 출처 표시, 동일 조건 공유가 필요합니다.

국가 내부의 선택 가능 지역은 공개 도메인 [Natural Earth](https://www.naturalearthdata.com/)의 현대 행정 경계를 1936년 국가 윤곽 안에 잘라 표시한 편집 단위입니다. 국가 간 경계는 역사 자료이지만 내부 행정선은 시대와 다를 수 있습니다. 지역 소유권 변경과 1938년 오스트리아·1939년 체코슬로바키아 사건은 저장 데이터와 지도 색에 반영합니다. 수동으로 바꾼 지역은 역사 사건이 덮어쓰지 않습니다. 별도 역사 지도 탭은 [OpenHistoricalMap](https://www.openhistoricalmap.org/)의 날짜별 지도를 현재 게임 월로 연결하며, 게임의 대체 역사 소유권은 그 원본 지도에는 반영되지 않습니다. 외부 지도에는 WebGL과 인터넷 연결이 필요합니다.

## 다음 단계

실제 1936년 국경 GeoJSON, 국가별 데이터팩과 AI 국가 행동, 전쟁/조약/선거 시스템을 차례로 확장할 수 있도록 시뮬레이션을 `src/engine.js`에 분리했습니다. 로컬 슬롯은 해당 기기에만 남고, 계정으로 로그인했을 때 클라우드 슬롯을 별도로 사용할 수 있습니다. Supabase의 `game_saves` 테이블은 소유자별 RLS를 적용합니다.
