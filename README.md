# 국가의 시간 · 1936

1936년 프랑스 제3공화국을 운영하는 브라우저 전략 시뮬레이터의 첫 플레이 버전입니다.

## 실행

Node.js 20 이상에서 `npm run dev`를 실행한 뒤 `http://localhost:4173`에 접속하세요. 의존성 설치는 필요하지 않습니다. `npm test`로 경제, 이벤트, 세이브 동작을 검증할 수 있습니다.

## 현재 구현

- 월 단위 시간 진행과 상호 연결된 세금, 예산, 성장, 실업, 물가, 여론, 안정도, 군수 모델
- 라인란트 진주부터 스페인 내전까지 1936년 사건 선택지와 1937년의 조건부 후속 사건
- 산업 투자, 사단 편성, 국가별 외교 행동
- 로컬 세이브 슬롯 세 개, Supabase 이메일 계정과 클라우드 세이브 슬롯 세 개
- 상황실, 경제, 정치, 군사, 외교, 연대기 화면과 모바일 레이아웃

역사적 사건의 배경과 게임의 계산 모델은 구분됩니다. 소유권 지도는 [Natural Earth](https://www.naturalearthdata.com/)의 공개 도메인 행정구역 경계로 나눈 유럽 지역 약 1,370개를 사용합니다. 지형은 실제 지리 데이터지만 행정구역은 현대 기준이므로 1936년의 모든 국경을 정확히 재현하지는 않습니다. 지역을 선택해 소유국을 바꾸면 세이브에 기록되며, 1938년 오스트리아와 1939년 체코슬로바키아 관련 선택으로 소유권이 달라집니다. 직접 바꾼 지역은 이후 역사 사건도 덮어쓰지 않습니다.

별도 역사 지도 탭은 [OpenHistoricalMap](https://www.openhistoricalmap.org/)의 날짜별 인터랙티브 지도를 현재 게임 월로 연결합니다. 이 자료는 공동 편집 데이터이며 지역과 시대에 따라 누락 또는 논쟁이 있을 수 있습니다. 게임의 임의 소유권 변경은 소유권 지도에 표시되고 역사 지도 원본에는 반영되지 않습니다. 역사 지도에는 WebGL을 지원하는 브라우저와 인터넷 연결이 필요합니다.

## 다음 단계

실제 1936년 국경 GeoJSON, 국가별 데이터팩과 AI 국가 행동, 전쟁/조약/선거 시스템을 차례로 확장할 수 있도록 시뮬레이션을 `src/engine.js`에 분리했습니다. 로컬 슬롯은 해당 기기에만 남고, 계정으로 로그인했을 때 클라우드 슬롯을 별도로 사용할 수 있습니다. Supabase의 `game_saves` 테이블은 소유자별 RLS를 적용합니다.
